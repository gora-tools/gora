# Security policy

## Reporting a vulnerability

Report a vulnerability privately, through GitHub Security Advisories on this repository:
open the **Security** tab and choose **Report a vulnerability**.

Do not open a public issue, pull request or discussion for a vulnerability, and do not
post the details anywhere public before a fix has been released.

A report is most useful with the affected version or commit, the steps to reproduce it and
what it allows an attacker to do.

## What to expect

GORA is maintained by one person, in their own time. Reports are read and answered on a
best-effort basis; no response or fix time is promised.

## Scope

The code in this repository. A vulnerability in a dependency belongs to that dependency's
project; a report here is welcome when GORA's use of it makes the impact worse.
